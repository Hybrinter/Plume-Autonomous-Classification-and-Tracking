# tools.ml_models.analysis.dataset_render

**Source:** `packages/tools/src/tools/ml_models/analysis/dataset_render.py`
**Kind:** module

## Purpose

This module orchestrates dataset figure and preview-gallery rendering
over an already-frozen `DatasetMeasurement`, and re-renders a verified
dataset bundle without re-measuring it. Preview bytes retain exact
canonical source arrays, figure coordinates are derived once into
frozen `DatasetFigure` recipes, and both render stages consume those
frozen records. One exclusive publisher call writes the summary, the
numerical evidence, the capture cache, and all indexed render
artifacts; `render_dataset_bundle` decodes the same persisted recipes
from a checksum-verified bundle and republishes it with a new
`PlotConfig`.

## Public interface

| Name | Kind | Description |
| --- | --- | --- |
| `publish_rendered_dataset` | function | Capture, render, and publish one dataset-analysis bundle |
| `render_dataset_bundle` | function | Re-render a verified dataset bundle without re-measuring |

## Inputs and outputs

`publish_rendered_dataset(measured: DatasetMeasurement, cfg:
DatasetAnalysisConfig) -> Result[Path, str]` takes the frozen
measurement and resolved config, and returns the published bundle
directory on `Ok`. `analyze_dataset` calls it after measurement.

`render_dataset_bundle(root: Path, summary: DatasetSummary, cfg:
PlotConfig, out: Path) -> Result[Path, str]` re-renders a verified
bundle; `render_analysis` dispatches dataset bundles here.

## Behavior

1. `capture_dataset_previews` copies exact canonical float32 arrays and
   explicit uint8 masks into checksum-bound NPZ `BundleFile` records
   under `previews/`, honoring the shared capture budget.
2. `dataset_figure_data` derives the frozen figure recipes once.
3. `render_dataset_figures` encodes every recipe into `figures/` bytes
   and per-figure availability records named `figure:<identifier>`.
4. `render_dataset_visuals` encodes every planned gallery into
   `visuals/` bytes and emits indexed placeholders named
   `gallery_unavailable_<family>` for skipped or unavailable families.
5. Three metadata JSON files record provenance: `figure-data.json`
   (recipe snapshot), `preview-manifest.json` (gallery plan plus exact
   preview identities), and `rendering.json` (the measurement id, a
   render identity derived from it and the `PlotConfig`, the resolved
   plot settings, and the render method). The render identity is
   distinct from the scientific measurement identity.
6. All generated bytes are bound to `ArtifactRef` records with explicit
   kinds and populations, then a single `publish_dataset_measurement`
   call persists everything; `figures` and `visuals` base availability
   records are replaced with the rendered states.

Required rendering failures abort before the output directory is
reserved. Missing metadata or budget-disabled optional galleries stay
explicit and produce indexed placeholders; nothing is dropped silently.

`render_dataset_bundle` reads only referenced files from a
checksum-verified bundle: the frozen `figure-data.json` recipes, the
`preview-manifest.json` plan and preview bytes, and `config.toml`
(which must re-digest to the summary's `config_digest`). Rendered
outputs must reproduce the frozen availability index exactly; the
republished summary replaces only `FIGURE`, `VISUAL`, and
`rendering.json` references, and every other file is byte-identical.
Missing or corrupt frozen documents fail with an actionable
fresh-analyze-required message.

## Errors and faults

Returns `Err` when preview capture, recipe rendering, gallery
rendering, reference binding, or publication fails. Publication errors
are the ones documented under
[`tools.ml_models.analysis.dataset_artifacts`](dataset_artifacts.md).

## Messages

None.

## Configuration

`DatasetAnalysisConfig` (`plot` and `capture` sections); see
[`tools.ml_models.analysis.config`](config.md).

## Constraints

- No scientific value is computed here; the measurement arrives
  frozen, and recipes and the gallery plan are derived once from it
  and persisted unchanged.
- Placeholder figures are rendered and indexed so absent outputs are
  visible in the bundle.
